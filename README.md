# Elancier

Static recreation of [elancier.com](https://elancier.com/) with a 2026 visual system applied in CSS (`css/theme-2026.css`). Page content, structure, and assets match the original site.

## Pages

- `index.html` — home
- `about-us.html`
- `services.html`
- `web-development.html`
- `creative-design.html`
- `mobileapp-development.html`
- `online-marketing.html`
- `portfolio.html` / `portfolio-details.html`
- `careers.html`
- `contact.html`
- `faq.html`

## Run locally

```bash
python3 -m http.server 8080
```

Open http://localhost:8080
